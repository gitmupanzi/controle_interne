# Conventions et devises

## Dates

Les dates visibles pour l'utilisateur sont affichées au format français :

```text
jour/mois/année
```

Lorsque l'heure est utile, elle est affichée explicitement.

## Colonnes

Les noms visibles doivent être en français. Pour les colonnes techniques, les accents et espaces sont évités et remplacés par `_`.

## Multisélection

Lorsque plusieurs valeurs peuvent être filtrées sans ambiguïté, les filtres doivent privilégier les sélections multiples.

## Devises

Règle commune :

```text
CDF + USD ne sont pas additionnés.
```

Les montants doivent être présentés par devise sauf lorsqu'une conversion officielle, datée et documentée est fournie.

## Exports

Les exports Word/PDF destinés à la lecture professionnelle utilisent une mise en page sobre. Les tableaux doivent garder uniquement les colonnes nécessaires à la décision.
