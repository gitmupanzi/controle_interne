# Qualité, sécurité et confidentialité

## Qualité des données

Les contrôles portent notamment sur :

- colonnes manquantes ;
- valeurs vides ;
- dates invalides ;
- doublons ;
- incohérences de solde ;
- mouvements nuls ;
- devises absentes ;
- rapprochements non trouvés.

## Alerte et anomalies

Les alertes doivent attirer l'attention du lecteur sans rendre les tableaux illisibles. Une bannière rouge ou rose clair est préférable à une coloration excessive de toutes les lignes.

## Confidentialité

La documentation web ne doit jamais publier :

- nom réel de client ;
- téléphone réel ;
- solde individuel réel ;
- numéro de compte réel ;
- secret ;
- chaîne de connexion ;
- mot de passe ;
- token.

Les exemples doivent rester anonymisés ou fictifs.
