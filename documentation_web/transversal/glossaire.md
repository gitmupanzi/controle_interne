# Glossaire

| Terme | Définition |
|---|---|
| Perfect Vision | Système métier microfinance et base opérationnelle |
| BB_VISION_PRO | Base SQL Server source de Perfect Vision |
| BB_VISION_REPORTING | Couche SQL décisionnelle destinée à Power BI |
| Perfect Power BI | Tableau de bord décisionnel Power BI |
| Solution Numérique | Module analytique pour les opérations digitales, M-Pesa, clients, épargne, crédits et statistiques |
| M-Pesa | Service mobile money utilisé dans les opérations numériques |
| G2 | Rapport M-Pesa de contrôle et d'enrichissement d'identité |
| DAT | Dépôt à terme / compte bloqué |
| Compte ouvert | Compte d'épargne courant du client |
| Crédit | Prêt accordé au client |
| Encours | Montant restant ou position actuelle selon le domaine |
| PAR | Portfolio at Risk, portefeuille à risque |
| KPI | Indicateur clé de performance |
| Grain | Niveau de détail d'une donnée |
| Flux | Mouvement sur une période |
| Instantané | Position à une date ou issue d'un export |
| Data gap | Donnée manquante empêchant un calcul fiable |
| Rapprochement | Comparaison entre deux sources |
| Déduplication | Suppression ou neutralisation des doublons |
| RLS | Row-Level Security, sécurité au niveau des lignes Power BI |
| DAX | Langage de mesures Power BI |
| Power Query | Moteur de transformation de données Power BI |
| PBIP | Format projet Power BI |
| TMDL | Format texte du modèle sémantique Power BI |
