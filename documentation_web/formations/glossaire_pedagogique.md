# Glossaire pédagogique

| Mot | Explication simple |
|---|---|
| KPI | Indicateur clé de performance. C'est un chiffre utilisé pour suivre une activité ou une situation. |
| Grain | Niveau de détail d'une analyse : client, compte, transaction, crédit, jour, mois, etc. |
| Source principale | Fichier ou base qui calcule réellement le chiffre. |
| Source de contrôle | Source qui vérifie ou enrichit une information sans remplacer la source principale. |
| G2 M-Pesa | Rapport M-Pesa utilisé pour contrôler les écritures et enrichir le nom client. |
| Compte ouvert | Compte d'épargne courant du client dans la Solution Numérique. |
| Compte bloqué / DAT | Dépôt à terme. L'argent est placé pour une durée donnée. |
| Encours | Montant restant ou position actuelle, selon le contexte. |
| PAR | Portefeuille à risque. Il indique une partie du portefeuille crédit à surveiller. |
| Rapprochement | Comparaison entre deux sources pour vérifier qu'elles parlent du même client ou de la même opération. |
| Numéro de téléphone normalisé | Téléphone nettoyé et harmonisé pour servir de clé entre Perfect Vision, Solution Numérique et G2. |
| Vue Client 360 | Lecture qui rassemble plusieurs informations d'un client : identité, activité, épargne, DAT, crédit et contrôles. |
| Période | Intervalle analysé entre une date de début et une date de fin. |
| Devise | Monnaie utilisée, par exemple CDF ou USD. Les devises ne doivent pas être additionnées sans conversion officielle. |
| Export | Fichier produit pour partager ou retraiter les résultats, par exemple Word, PDF ou Excel. |
