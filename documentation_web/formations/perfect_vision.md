# Formation Perfect Vision

## Objectif du module

Perfect Vision est la source métier historique de la microfinance. Cette formation aide à comprendre les cycles de contrôle, les requêtes SQL et les indicateurs qui peuvent alimenter les tableaux de bord et les rapports.

## 1. Ce qu'il faut comprendre

Perfect Vision contient les données opérationnelles de la microfinance : clients, crédits, épargne, opérations, remboursements, portefeuille, risques et contrôles.

Le rôle de la formation est de montrer :

- où se trouvent les données ;
- comment les requêtes produisent les indicateurs ;
- pourquoi certaines analyses sont prioritaires ;
- comment relier les résultats à un cycle de contrôle interne.

## 3. Requêtes SQL prioritaires

Le fichier `data/vision/requetes.sql` sert de catalogue de travail. Les requêtes avec un niveau d'importance 9 ou 10 doivent être lues comme des candidats prioritaires pour :

- les tableaux de bord ;
- les rapports de direction ;
- les contrôles internes réguliers ;
- les analyses Power BI.

## 4. Lien avec la Solution Numérique

Perfect Vision et la Solution Numérique peuvent être rapprochés par le numéro de téléphone normalisé. Ce lien permet de construire une vue plus complète du client :

- identité et historique métier dans Perfect Vision ;
- activité digitale, épargne numérique, DAT et crédits numériques dans la Solution Numérique.
